# V21 Reference Notes

The visual rebuild takes structural inspiration from two categories of current competitive tools without copying their UI:

1. Champion guide products that keep overview, builds, matchups and strategy in one champion-centered flow.
2. Fearless draft products that prioritize broadcast readability, team identity, tournament context and fast draft control.

FROMBOS adapts those principles into a coach-first Wild Rift workspace: Command Center -> Champion Intelligence -> Composition Lab -> Draft Room -> Tactical/VOD review.
